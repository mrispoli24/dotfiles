# Palahniuk Craft Editor Skill

Drop this folder into your `.agents/skills` directory.

Suggested path:

```txt
~/.agents/skills/palahniuk-craft-editor/
```

Contents:

- `SKILL.md` — main operational agent skill.
- `references/craft-map.md` — maps source essays to editing lenses.
- `references/essay-digests.md` — concise digest of each source essay.
- `references/revision-checklists.md` — practical editing checklists.
- `references/examples.md` — before/after examples.
- `references/michael-style-notes.md` — Michael-specific writing preferences.

This packet uses digests and operational craft notes rather than reproducing the full source text.
